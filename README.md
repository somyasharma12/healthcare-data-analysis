
# Healthcare Data Analysis & Management

## 📌 Project Overview

This project focuses on analyzing healthcare data using SQL Server,
Python, Microsoft Excel, and Power BI.

The objective of the project is to organize healthcare data, perform
data analysis, identify useful insights, and create interactive
dashboards for better understanding of hospital operations and
financial performance.

## 🛠️ Tools & Technologies

- SQL Server
- Python
- Pandas
- Matplotlib
- Seaborn
- Microsoft Excel
- Power BI
- DAX

## 🗄️ Database

The healthcare database contains multiple related tables, including:

- Patients
- Doctors
- Departments
- Staff
- Appointments
- Admissions
- Entry & Exit
- Diagnoses
- Treatments
- Bills
- Payments
- Insurance

## 🔍 SQL Analysis

SQL was used to:

- Analyze patient demographics
- Analyze appointments and admissions
- Calculate total revenue
- Analyze payments
- Calculate outstanding amounts
- Analyze department-wise revenue
- Perform JOIN-based analysis across tables

## 🐍 Python Analysis

Python was used for Exploratory Data Analysis (EDA).

Libraries used:

- Pandas
- Matplotlib
- Seaborn

Analysis included:

- Patient demographics
- Appointment analysis
- Bill amount analysis
- Revenue trends
- Data quality checks

## 📊 Excel Dashboard

The Excel dashboard was created using:

- PivotTables
- PivotCharts
- Slicers
- KPI summaries

## 📈 Power BI Dashboard

The Power BI dashboard contains four analytical pages:

1. Healthcare Overview
2. Doctor & Patient Analysis
3. Financial Analysis
4. Insurance Analysis

DAX measures were used to calculate important KPIs such as:

- Total Patients
- Total Doctors
- Total Appointments
- Total Revenue
- Total Payments
- Outstanding Amount
- Average Bill
